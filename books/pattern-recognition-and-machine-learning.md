# Pattern Recognition and Machine Learning

Christopher Bishop — 2006

## Three key theories

1. **The Bayesian treatment of machine learning** — Bishop casts learning as probabilistic inference: priors over parameters, likelihoods, and posterior predictive distributions. Integrating over parameters, rather than fixing them, controls overfitting and quantifies uncertainty. Model comparison uses the evidence.
2. **Probabilistic graphical models** — Directed and undirected graphs encode how joint distributions factor into local pieces. The structure exposes conditional independence and enables efficient inference by message passing. Graphs give a common language for many models.
3. **Latent variables and approximate inference** — Hidden variables explain observed data, as in mixture models and hidden Markov models. Expectation–maximization fits them. When exact inference is intractable, variational methods and sampling approximate the posterior.
