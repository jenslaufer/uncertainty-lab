# A Thousand Brains

Jeff Hawkins — 2021

## Three key theories

1. **Cortical columns as universal modeling units** — The neocortex consists of about 150,000 columns running the same algorithm. Each column learns complete models of objects, not fragments. Their uniformity explains why the cortex handles vision, touch, and language alike.
2. **Reference frames** — Columns store knowledge in reference frames, built from grid-cell-like and place-cell-like mechanisms. Sensory input is tied to locations, and movement updates the location. Thinking itself is movement through reference frames, for concrete objects and abstract concepts alike.
3. **Voting among thousands of models** — There is no single model of an object but thousands, one per column. Columns vote through long-range connections to reach a consensus, which is what we perceive. Hawkins argues true AI must adopt this sensorimotor, reference-frame-based learning.
