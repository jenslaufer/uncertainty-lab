# The Model Thinker

Scott Page — 2018

## Three key theories

1. **Many-model thinking** — Every model is wrong; a collection of diverse models is less wrong. The diversity prediction theorem shows that crowd error equals average error minus diversity. Combining models beats betting on one.
2. **REDCAPE: the uses of models** — Models serve seven purposes: Reason, Explain, Design, Communicate, Act, Predict, Explore. Naming the purpose tells you which model to pick and how to judge it.
3. **The wisdom hierarchy** — Data become information, information becomes knowledge, knowledge becomes wisdom. Models organize this climb. Wisdom means knowing which model to apply when.
