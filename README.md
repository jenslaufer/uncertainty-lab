# uncertainty-lab

Build knowledge, research, and run experiments where these fields meet:

uncertainty · randomness · probability theory · statistics · math ·
complexity science · emergence · network theory · scaling theory ·
evolution · neuroscience · human intelligence · computer science · AI ·
economy · investment · antifragility · explore vs. exploit

The value lies in the overlaps, not in any single field. One question drives
everything: **how do systems — brains, markets, species, algorithms — act
well when they cannot know what comes next?**

## Structure

- `notes/` — one concept per file. Define it, link it to other notes, name the source.
- `questions/` — open research questions. Each states what would answer it.
- `experiments/` — simulations and data analyses. One folder each, with code,
  result, and a short conclusion.
- `sources/` — books, papers, talks. One file each: core claim, evidence, own critique.

## Rules

- Write in English.
- Link across fields. A note that connects to nothing is not done.
- Separate claim from evidence. Mark speculation as such.
- Experiments must be reproducible: fixed seeds, pinned dependencies, data source named.
- Python (polars, numpy) or R (tidyverse, Quarto) for experiments.
